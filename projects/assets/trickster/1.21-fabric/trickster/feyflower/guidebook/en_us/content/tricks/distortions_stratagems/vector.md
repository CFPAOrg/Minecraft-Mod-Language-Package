While much vector math can be done with basic [arithmetic](*trickster:tricks/distortions_stratagems/arithmetic) tricks, 
some operations require more specialized functionality.
This chapter provides some of these.

;;;;;

#<trickster:trick id="trickster:extract_x" />

Returns the X component of the given vector.

;;;;;

#<trickster:trick id="trickster:extract_y" />

Returns the Y component of the given vector.

;;;;;

#<trickster:trick id="trickster:extract_z" />

Returns the Z component of the given vector.

;;;;;

#<trickster:trick id="trickster:merge_vector" />

Merges three input numbers into a vector.

;;;;;

#<trickster:trick id="trickster:length" />

Returns the length of the given vector.

;;;;;

#<trickster:trick id="trickster:dot_product" />

Returns the dot product of the given vectors.

;;;;;

#<trickster:trick id="trickster:cross_product" />

Returns the cross product of the given vectors.

;;;;;

#<trickster:trick id="trickster:normalize" />

Normalizes the given vector to a length of one.

;;;;;

#<trickster:trick id="trickster:align_vector" />

Normalizes the given vector to a length of one and aligns it to the nearest cardinal axis.
