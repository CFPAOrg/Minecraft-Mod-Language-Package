# <Color id="light_purple">气泡锚</Color>

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="bubble_anchor" scale="2"/>
  抑制15x15x15立方体内的海水，留出干燥的空间搭建建筑。
</Column>

放下气泡锚，放入燃料，它就会抑制它周围立方体区域内的水：你可以在其中行走、挖掘、搭建，和在陆地上一样。区域外部的水无法侵入。区域边界由较淡的气泡环标识。

区域内的海带、海草、气泡柱会被清理，且会抽干含水方块的水。你放下的水会被直接抑制。

***

## <Color id="gold">燃料</Color>

向燃料槽放入燃料。也接受漏斗和管道。

| 燃料     | 时间  |
| -------- | ----- |
| 干海带块 | 2分钟 |
| 海泡菜   | 30秒  |
| 干海带   | 12秒  |
| 海带     | 6秒   |

它会在最后一份燃料耗尽前10秒发出一次警报。槽位旁的条栏能显示剩余量。

***

## <Color id="gold">解除力场后</Color>

燃料耗尽时、手动关闭时、锚被破坏时力场都会消失。若是燃料耗尽和手动关闭，被抑制的水会从外沿向内逐渐释放。若是破坏，则所有的水会同时释放。

**结束至**按钮用于指定向空间填充什么方块：

* 水：向所有你未搭建方块的位置注入海水。不会影响你搭建的方块。
* 空气：区域留空。可在建好外墙之后使用该模式，此后内部即能保持干燥。如果外部仍敞开，那么外界的海水会自行流回区域内。

**基准**按钮用于指定立方体区域的位置。“中央”视锚为中心。“顶部”会将区域置于锚上方，方便海床上的锚清除它上方的海水。

***

## <Color id="gold">激光功率</Color>

向任意面发射至少有20 AP的激光，可让锚不依赖燃料运作；撤去激光后力场还会再维持2秒。激光越纯净，力场范围就越大：

| 纯度    | 力场         |
| ------- | ------------ |
| 1.5以下 | 15 x 15 x 15 |
| 1.5     | 17 x 17 x 17 |
| 2.0     | 21 x 21 x 21 |
| 2.5     | 25 x 25 x 25 |

激光可将锚变为永久性干船坞，以便在水下建造大型建筑。[海晶水晶](laser_power.md)发出的光束可将力场扩张至最大。

力场尺寸、激光功率、燃料时间、运作速度均可在`config/nautec-common.toml`中配置。

## <Color id="gold">气泡胶囊</Color>

<Row>
  <ItemImage id="bubble_capsule"/>
  ### <Color id="aqua">耗尽空气时使用</Color>
</Row>

一次性的紧急空气胶囊。在水下对头部使用，可推离头部周围5x5x5区域内的海水，持续30秒，同时补满你的氧气条。

这种气室和小型气泡锚力场类似：外部的水不受影响，效果结束时内部搭好的方块不会损毁。气泡消失前5秒会发出警报，随后海水就会回到所有未搭建方块的位置。在原本的头部位置放置方块，可提前让气室消失。

气室尺寸和持续时间均可在`config/nautec-common.toml`中配置。
