# <Color id="light_purple">生产率</Color>

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="minecraft:clock" scale="2"/>
  菌落在反应机中产出产物的速度，以及该操作所需的功率。
</Column>

此处的数据同时适用于[生物反应机](bio_reactor.md)和[工业生物反应机](industrial_bio_reactor.md)。工业生物反应机不会加快各个菌落的速度，只是能容纳更多菌落和升级。

***

## <Color id="gold">计算公式</Color>

每刻，工作中菌落的进度会推进：

每刻推进量 = 生产率 x 大小因数 x 基础速度 x 品系产量 x 速度增益

* 生产率是菌落的统计数据，最高可为2（[细菌统计数据](bacteria_stats.md)）。
* 大小因数为0.5 + 0.5 x 大小 / 40,000，微型菌落的因数为0.5，达到最大时因数为1。
* 两种生物反应机的基础速度均为16.8，均可配置。
* 品系产量由品系决定，参见下表。
* 速度增益为1，每个[反应机速度升级](reactor_upgrades.md)追加0.5。

达到100点进度时会完成当前生产周期，并向菌落的输出槽放入1个产物，每个反应机产量升级追加1个。残余的进度会汇入下一周期。1分钟为1,200刻，所以：

每分钟产物量 = 每刻推进量 x 12 x 每周期物品数

***

## <Color id="gold">品系产量</Color>

所有品系都可选育至相同的生产率上限，默认为2.0。计算时会用品系产量乘以生产率，但生产率上限还是原来的值。跟着[诱变机页面中的统计数据选育步骤](mutator.md#统计数据选育)操作，可避免优化改造影响到你的最优模板菌落。

JEI的生物反应机分类和已分析培养皿的提示文本中均会显示品系的品系产量。整合包可通过品系JSON文件中可选的`production_multiplier`字段设置品系产量，默认值为1。

## <Color id="gold">范例</Color>

使用统计数据达到最大（生产率为2，大小为40,000）的菌落，不带升级：

| 品系产量            | 每刻进度 | 每份产物耗时 | 每分钟产物量 |
| ------------------- | -------- | ------------ | ------------ |
| 1（石头）           | 33.6     | 0.15秒       | 约403        |
| 0.8（煤炭、铜）     | 26.9     | 0.19秒       | 约323        |
| 0.6（铁）           | 20.2     | 0.25秒       | 约242        |
| 0.5（红石、青金石） | 16.8     | 0.3秒        | 约202        |
| 0.4（金）           | 13.4     | 0.37秒       | 约161        |
| 0.12（钻石）        | 4.03     | 1.2秒        | 约48         |
| 0.1（绿宝石）       | 3.36     | 1.5秒        | 约40         |

全新菌落的速度远慢于上表。生产率为0.4、大小为400的嗜铁菌每刻推进0.4 x 0.505 x 16.8 x 0.6 = 2.04点进度：每2.5秒1个铁锭，每分钟24个。

升级会乘算上述数据。配有两个反应机速度升级时，达到极限的钻石菌落每分钟约产出97颗钻石；配有两个产量升级时每周期产出3个物品，即每分钟约为145颗。

达到极限的石头菌落会在约十秒内填满输出槽（容量为64个物品），而满输出槽会暂停相应的菌落；务必确保产物能被按时抽出。

## <Color id="gold">所需功率</Color>

功率只是阈值。反应机需要每刻收到一定量的AP，不然就不会进行产出，还会重置当前进度。更强大的光束可加快产出，参见[更强大的光束](nautec:getting_started/stronger_beams.md)。

所需AP = (基值 + 每菌落能耗 x 有菌落槽位数) x 各升级乘数，向上取整

| 反应机         | 基值 | 每菌落能耗 | 填满，无升级      |
| -------------- | ---- | ---------- | ----------------- |
| 生物反应机     | 5    | 15         | 3个菌落时为50 AP  |
| 工业生物反应机 | 100  | 50         | 9个菌落时为550 AP |

所有四个数据均可配置。空的菌落槽无能耗。[反应机升级](reactor_upgrades.md)中列出了升级乘数和常用升级方案的能耗。
