# <Color id="light_purple">传输激光功率</Color>

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="laser_junction" scale="2"/>
  将海蓝能量（Aquatic Power，AP）从来源输送至需要它的机器。
</Column>

## <Color id="gold">光束的运作原理</Color>

所有海蓝科技机器的运转都需要海蓝能量，这种能量又由激光束传输。光束有功率，单位为AP/t。方块无法储存功率，机器也不会消耗功率：只要收到的AP/t足够，机器就能运转。

* 光束沿直线传播，大多数激光方块发射的光束最远可至16格，中继器最远64格（两者均可配置）。
* 光束会被路径中第一个有判定箱的方块阻挡。水、玻璃、玻璃板则不会，染色与否不影响；可以用玻璃包埋光束，以免他人误触。充能器等低矮的激光方块也会阻断侧面射来的光束，哪怕看上去会从上方掠过也一样。
* 光束只会在远端面能接受时发射。每半秒重新检查一次连接。
* 有功率的光束会灼烧它经过的所有生物和玩家，每秒灼烧两次。每次造成的伤害与光束功率的平方根成正比，也即和机器加速的变化曲线一致：10 AP的光束造成3点伤害（一颗半红心），40 AP造成6点，160 AP造成12点，1,000 AP造成30点。抗火效果可抵御激光伤害。这些数据可通过`config/nautec-common.toml`中的`laserDamage`、`laserDamageReferencePower`、`laserDamageScaling`、`laserDamageMax`配置。
* 将物品投入有功率的光束，可进行[物品转化](nautec:getting_started/item_transformation.md)。

光束还具有纯度，部分配方有纯度要求。调整激光路径对纯度的影响参见[激光光学](nautec:deep_engineering/beam_optics.md)。

<Color id="gold">提示</Color>：透过<ItemLink id="prism_monocle"/>观察激光方块，可查看它收到的功率和纯度。

## <Color id="gold">机器的需求</Color>

| 机器                              | 需要的AP/t                                             |
| --------------------------------- | ------------------------------------------------------ |
| [搅拌机](mixer.md)                | 大于等于10                                             |
| [深海排水口](drain.md)            | 大于20                                                 |
| [充能器](charger.md)              | 任意（物品会尽可能接收光束功率，最多至物品自身的上限） |
| [钓鱼站](fishing_station.md)      | 大于等于1                                              |
| [约束刷怪笼](confined_spawner.md) | 50可持续运转（小于50变为脉冲式）                       |

燃烧海晶碎片的<ItemLink id="aquatic_catalyst"/>会输出12 AP/t，燃烧海晶水晶碎片输出20，海晶砂粒输出6。上表的机器需求均可配置。

<Row>
  <ItemImage id="prismarine_laser_relay"/>
  ### <Color id="aqua">海晶石激光中继器</Color>
</Row>

从后面接受光束，再从前面送出，最远送至64格处（`relayLaserDistance`）。输出光束的功率和纯度不变，连续使用中继器即可长距离传输。中继器可放置在水下。

对其他激光方块放置时，中继器会自行与方块对齐。将其放在激光源的发射面上（催化器透镜、其他中继器的前面），它即会接受光束，并从前面传递出去。将其放在接受光束的机器上，它即会指向该机器。若放在其他方块上，它的前面会指向你的视线方向。空手右击可打开朝向调整界面，其中会显示所有六个面，其中“前面”为朝向你的那一面。可借此调整被遮挡的面。在界面中点击某一面可将其设为输出，右击设为输入；对侧面会自动设为输入/输出。也可用旋转模式的<ItemLink id="aquarine_steel_wrench"/>右击将其旋转至下一个方向。

<Row>
  <ItemImage id="laser_junction"/>
  ### <Color id="aqua">激光转接器</Color>
</Row>

能够合并光束，可自行选择输出位置。所有六面都可分别设置输入、输出、关闭，初始时所有面均关闭。

* 空手右击可打开显示所有六面的调整界面，其中“前面”为朝向你的那一面。点击某一面可在关闭、输入、输出间切换，右击反向切换。可在其中调整被挡住的面。
* 用<ItemLink id="aquarine_steel_wrench"/>右击某一面可将其设为输入。再次右击可关闭。
* Shift右击可将面设为输出。再次右击可关闭。

传输时会求所有输入的功率和，并在所有输出端间均分，向下取整。向两个输出发送25 AP，每个收到12 AP。输出的纯度接近于所有输入中最纯净的，但与之相差它和各输入平均纯度差值的四分之一。中断的输入视作纯度为0，会少量降低输出光束的纯度。

输出也可设置功率上限。在调整界面中的输出上滚动滚轮，可设置该面每刻输出的AP上限；按住Shift时步长为1，Ctrl步长为10，在上限为1时向下滚动会取消上限。未送至有上限输出端的功率会在剩下的输出端间均分，而不是所有输出端一起均分。可借此用一条光束驱动一排机器：给所有机器配上转接器，指向机器的输出面上限设置为机器所需量，剩余的部分就会送至下一个转接器。通过这种方式，100 AP的光束就可驱动五台20 AP的机器，各级转接器分别收到80、60、40 AP，而不是各级减半。配置卡能复制各面的上限。

可用转接器汇合两个较弱的来源，例如两个催化器至一台[深海排水口](drain.md)。也可用它让激光转向（一个面输入、另一个面输出），或用它将一条光束均分至五台机器，后两种用途都不会损失纯度。

## <Color id="gold">加长和弯折光束</Color>

连续使用中继器可加长距离，需要光束转向或分叉则应使用激光转接器。能提高纯度的聚焦透镜参见[激光光学](nautec:deep_engineering/beam_optics.md)。若需横跨整张地图或跨维度传输功率，可见[海棱人造卫星](nautec:deep_engineering/prism_satellite.md)。

## <Color id="gold">激光P2P通道</Color>

安装有应用能源2时，光束也可通过ME网络传递。用海晶石激光中继器或激光转接器右击ME P2P通道，可将其调谐为激光P2P通道，随后和其他P2P通道一样用内存卡链接即可。

* 使用任意激光方块向范围内的输入侧通道面发射光束。光束会像射中机器一样射中通道。
* 各输出侧通道会为相贴的激光方块供应功率，如同该面被光束射中。方块的该面也需能接受光束。
* 通道会在所有需要功率的方块间均分功率，纯度不变。100 AP的光束送至两个输出侧，每个会收到50 AP。
* 和其他P2P通道一样，激光通道需要占用频道，也需要ME网络供能。即便有一项没有满足，光束也会发射，只是输出侧不会继续输出功率了。

输出侧通道不会将光束送回上游的方块，避免用通道形成回路来增加功率。
