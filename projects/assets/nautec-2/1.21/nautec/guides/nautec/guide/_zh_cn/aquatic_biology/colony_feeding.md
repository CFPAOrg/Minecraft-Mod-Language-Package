# <Color id="light_purple">菌落喂食</Color>

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="minecraft:bone_block" scale="2"/>
  反应机营养物质槽中的营养物质可阻止菌落老化。
</Column>

本页内容同时适用于[生物反应机](bio_reactor.md)和[工业生物反应机](industrial_bio_reactor.md)。

***

## <Color id="gold">营养物质缓存</Color>

每个菌落槽都有一个营养物质缓存，显示为菌落旁边的细条栏。菌落生产时，它会按时间消耗营养物质，不会老化。缓存耗空后，反应机会从营养物质槽中取一个相应的营养物质，按照相应配方的刻数补充缓存。一份营养物质可为收到它的缓存补充足够使用1,200刻（1分钟）的量，使用储物方块则补充九倍的量。

也即，每个工作中的菌落每分钟消耗一份营养物质。缓存只会在菌落工作时消耗：反应机功率不足或相应输出槽已满时，即不会消耗缓存。[反应机效率升级](reactor_upgrades.md)可让每份物品续航更长时间。

将鼠标悬停在条栏上可查看剩余秒数。缓存为空且没有相应营养物质时，条栏会显示“无营养物质：菌落会逐渐老化”，菌落的老化规律参见[细菌统计数据](bacteria_stats.md)。没有营养物质的衰老菌落每工作1秒缩小2%，放入一份营养物质可立即阻止其缩小。喂食不会重置菌落的寿命，只有[培养机](incubator.md)能重置。

***

## <Color id="gold">营养物质种类</Color>

不同品系的营养物质不同，默认是该品系菌落在培养机需要的物品。JEI的菌落喂食分类中列出了所有对应关系：查询品系可查看其营养物质，或可查看物品用途以检查哪些品系需要它。下方给出几例：

| 品系           | 营养物质     |
| -------------- | ------------ |
| 嗜岩石菌       | 石头         |
| 嗜硅菌、盐养菌 | 沙子         |
| 嗜脂质菌       | 海带浆       |
| 嗜钙菌         | 骨块         |
| 绯红微生物     | 绯红菌岩     |
| 噬碳菌         | 任意煤矿石   |
| 嗜铁菌         | 任意铁矿石   |
| 嗜金刚菌       | 任意钻石矿石 |
| 嗜铅菌         | 铅锭         |

对应其他模组金属和宝石的品系会食用它们产出的那种金属或宝石，可以直接把反应机输出的一小部分送回营养物质槽。

除原本的营养物质外，各品系还能食用它产出的物品，以及该物品的储物方块。嗜铁菌不仅接受铁矿石，还接受铁锭和铁块；根际细菌除小麦外还接受干草捆；产锡细菌也接受锡块。产物的填充量和营养物质一样，储物方块的填充量是其九倍。此规律适用于其他模组的品系和`/nautec bacteria generate`注册的品系。JEI也会列出这些品系的营养物质。

蓝细菌、盐细菌、甲烷菌、嗜热菌没有对应的营养物质，它们工作时必定会老化。

***

## <Color id="gold">营养物质槽</Color>

生物反应机有2个营养物质槽，工业生物反应机有3个。它们只接受适用于其中品系的物品。有菌落需要喂食时，反应机会按序检查营养物质槽，并消耗遇到的第一个所需营养物质；一个堆叠就可供应所有该品系的菌落。

每个槽位只能容纳一种营养物质，也即生物反应机最多只能同时供应两种营养物质，工业生物反应机最多三种。若要保证所有菌落都有稳定的营养物质供应，填充菌落时建议选取共享营养物质的，或控制品系数量。不适用于任何菌落的营养物质只会白白占用反应机的槽位。

***

## <Color id="gold">自动化营养物质</Color>

漏斗和管道可以送入营养物质：

* 生物反应机：从生物反应机方块顶面送入，比如在上方放置漏斗；或也可从底座的底面用管道送入。
* 工业生物反应机：从任意方块的外表面送入，比如在顶板上方放置漏斗。

自动化设施只会把营养物质送到营养物质槽，把升级送到升级槽，而且无法取出它们。输入缓存放一箱子的营养物质，再及时抽走产物，就足够让反应机无限期运作下去了。

***

## <Color id="gold">更改整合包中的喂食配方</Color>

喂食配方由数据驱动。各营养物质对应关系都是一个类型为`nautec:colony_feeding`的配方，实装品系的文件为`data/nautec/recipe/colony_feeding/<品系>.json`，可用数据包替换或再新增。

| 字段             | 意义                                                                                                             |
| ---------------- | ---------------------------------------------------------------------------------------------------------------- |
| `bacteria`       | 品系ID、带`#`的细菌标签，或留空以匹配所有品系。                                                                  |
| `ingredient`     | 下含`ingredient`物品和可选字段`count`（默认为1）的对象。营养物质槽中必须至少有该数量的物品，一次喂食会消耗一批。 |
| `vitality_ticks` | 一份营养物质补充的缓存量。                                                                                       |

有多个配方为菌落指定相同物品时，指明品系的配方优先于细菌标签生效，细菌标签优先于通配生效。有文件的配方优先于自动注册的产物和储物方块配方生效。

储物方块从`c:storage_blocks/<材料>`标签下寻找，匹配物品的`c:ingots`、`c:gems`、`c:dusts`标签。小麦、骨粉等没有此意义上储物方块的物品，已在`nautec:storage_blocks`物品数据映射中指明了对应关系；也即可用数据包添加。`config/nautec-common.toml`中的`bacteriaProductNutrients`可关闭储物方块对应规则。`/nautec bacteria generate`会在每次创建品系时写入喂食配方，参见[自定义细菌](custom_bacteria.md)。
