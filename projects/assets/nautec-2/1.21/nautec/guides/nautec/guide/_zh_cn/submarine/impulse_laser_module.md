# <Color id="light_purple">冲击激光</Color>

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="impulse_laser_module" scale="2"/>
  两道向前发射的光束。
</Column>

按住激活键时，冲击激光模块会从潜水器的前部发出两道光束，和让两把海洋步枪开火类似。光束会在你的十字准星处交汇。

***

## <Color id="gold">使用</Color>

|            | 默认                                                        |
| ---------- | ----------------------------------------------------------- |
| 蓄能       | 过半秒后光束才会出现                                        |
| 爬升       | 连续开火5秒可达到最大强度                                   |
| 能耗       | 每刻400，爬升至每刻1,400                                    |
| 范围       | 64格                                                        |
| 各光束伤害 | 2爬升至6，有0.4%概率升至目标最大生命值的1.25%，每秒四次攻击 |

在模块栏中选择模块，按住攻击或激活键。激光会先蓄能半秒，随后两道一起开火。开火的时间越长，光束就越宽越亮，攻击力也越高；开火五秒后即达到最大强度。松开按键会立即停止发射光束，再次发射需要重新蓄能。

光束方向取决于潜水器的朝向：潜航时，两道光束会交汇于准星处的生物或固体方块，若没有目标则使用极限射程。光束会跟随潜水器的前部而非你的视角，也即自由观察时仍会按潜水器的朝向发射。光束会被遇到的第一个生物或固体方块阻挡，被两者同时击中会受到两者的伤害。光束伤害忽略护甲，且不会波及乘员。

***

## <Color id="gold">能耗</Color>

爬升完毕的光束每秒消耗28,000点储能，较短脉冲的续航长于长时间开火。能量库储能过低时，乘员离开潜水器时，以及模块被取出时均无法发射光束。

所有数据均可配置。
