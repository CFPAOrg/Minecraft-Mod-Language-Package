# <Color id="light_purple">品系树</Color>

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="mutator" scale="2"/>
  品系之间如何突变、所需的诱变剂、突变概率。
</Column>

除移植得到的品系外，所有品系都需在[诱变机](mutator.md)中突变得到。下方表格中的每一行都代表一种突变：向诱变机放入亲本品系的菌落，同时放入诱变剂。诱变剂不会消耗。整合包可改变相关配方；JEI的细菌突变分类会显示当前配方，菌株谱系分类则会显示从移植开始到达任意品系的最快路径。查询装有该品系菌落的培养皿可查看相关配方。

***

## <Color id="gold">突变耗时</Color>

平均来说，全新菌落在10 AP的光束下（每12秒尝试一次）：

| 概率 | 尝试次数 | 耗时        | 有增强剂   |
| ---- | -------- | ----------- | ---------- |
| 75%  | 1或2     | 约15秒      | 1次尝试    |
| 30%  | 3或4     | 约40秒      | 1或2次尝试 |
| 15%  | 约7      | 不到1.5分钟 | 2或3次尝试 |
| 9%   | 约11     | 约2分钟     | 约4次尝试  |
| 5%   | 20       | 4分钟       | 约7次尝试  |
| 3%   | 33       | 约7分钟     | 约11次尝试 |

使用40 AP的光束可让耗时减半。增强剂中的电解藻类浆液试管可让概率变为三倍，并阻止突变失败导致的菌落缩小；增强剂会在成功突变时消耗。

## <Color id="gold">石头、矿物、金属</Color>

最有价值的分支。从海晶母岩上移植嗜岩石菌可跳过第一步突变，在铁、红石、青金石及之前所有突变配方的概率为15%；金、钻石、绿宝石的为5%。

| 品系                 | 产物   | 亲本       | 诱变剂       | 概率 |
| -------------------- | ------ | ---------- | ------------ | ---- |
| 嗜岩石菌             | 石头   | 嗜热菌     | 石头         | 15%  |
| 嗜钙菌               | 骨粉   | 嗜岩石菌   | 骨粉         | 15%  |
| 嗜硅菌               | 沙子   | 嗜岩石菌   | 沙子         | 15%  |
| 噬碳菌               | 煤炭   | 嗜岩石菌   | 煤炭         | 15%  |
| 嗜金属菌             | 铜锭   | 噬碳菌     | 铜锭         | 15%  |
| 嗜铁菌               | 铁锭   | 嗜金属菌   | 铁锭         | 15%  |
| 嗜酸菌               | 红石   | 嗜金属菌   | 红石         | 15%  |
| 嗜青金菌             | 青金石 | 嗜金属菌   | 青金石       | 15%  |
| 嗜硫菌               | 火药   | 嗜酸菌     | 火药         | 15%  |
| 嗜金菌               | 金锭   | 嗜铁菌     | 金锭         | 5%   |
| 嗜金刚菌             | 钻石   | 嗜金菌     | 钻石         | 5%   |
| 嗜绿宝石菌           | 绿宝石 | 嗜金刚菌   | 绿宝石       | 5%   |
| 嗜海晶菌             | 无     | 嗜绿宝石菌 | 海洋金锭     | 5%   |
| 嗜海晶菌（优化改造） | 无     | 嗜海晶菌   | 海晶水晶碎片 | 25%  |

嗜硫菌也可在热液喷口区中的喷口管虫处移植获得。

从移植所得嗜岩石菌菌落出发的最短路径：

| 目标             | 路线                         | 突变次数 |
| ---------------- | ---------------------------- | -------- |
| 煤炭             | 嗜岩石菌, 噬碳菌             | 1        |
| 铜               | 再是嗜金属菌                 | 2        |
| 铁、红石、青金石 | 再是嗜铁菌、嗜酸菌或嗜青金菌 | 3        |
| 金、火药         | 再是嗜金菌或嗜硫菌           | 4        |
| 钻石             | 再是嗜金刚菌                 | 5        |
| 绿宝石           | 再是嗜绿宝石菌               | 6        |
| 嗜海晶菌         | 再是嗜海晶菌                 | 7        |

若从嗜热菌起始，所有品系的突变次数均加1。你需要路径中每一步所需的诱变剂各一份，而由于诱变剂不会消耗，一个铁锭就能永久性解锁嗜铁菌了。

嗜海晶菌在生物反应机中没有产物。它们是[细菌富集催化机](nautec:deep_engineering/bacterial_enrichment_catalyst.md)使用的原料。

## <Color id="gold">其他模组的材料</Color>

对应其他模组中金属和宝石的品系只会在安装有添加该材料的模组时出现。诱变剂必定是相应材料的锭或宝石，所用亲本取决于稀有程度：

| 亲本     | 概率 | 材料                                                                                                          |
| -------- | ---- | ------------------------------------------------------------------------------------------------------------- |
| 嗜岩石菌 | 30%  | 铝、铝土矿、黄铜、青铜、石墨、铅、生铁、钢、锡、锌、磷灰石                                                    |
| 嗜金属菌 | 30%  | 银、镍、锑、铋、硼、康铜、琥珀金、殷钢、玫瑰金、不锈钢、紫水晶青铜，红宝石、蓝宝石、橄榄石、黄玉/托帕石等宝石 |
| 嗜铁菌   | 5%   | 锇、铀、钴、钛、钨和大多数其他中级金属，赛特斯石英、焦黑石英                                                  |
| 嗜金菌   | 5%   | 铂、铱、钯、末影等珍贵金属                                                                                    |
| 嗜金刚菌 | 3%   | 下界合金、ATM、振金、难得素等顶级金属                                                                         |

[生产率](production_rates.md)中完整给出了各品系的品系产量。

## <Color id="gold">优化改造</Color>

有产物的品系也可突变为自身。这种操作需要使用诱变剂的储物方块（嗜铁菌使用铁块，根际细菌使用干草捆），没有储物方块使用物品本身。优化改造的成功概率为概率基值的25%，会保留品系和菌落大小不变，并少量改动其统计数据。这也是从已有品系中选育更优菌落的方法。参见[诱变机](mutator.md)。
