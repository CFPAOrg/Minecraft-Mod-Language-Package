# <Color id="light_purple">玩家强化</Color>

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="claw_robot_arm" scale="2"/>
  你的身体有九个强化件槽位，每个槽位都能容纳一种强化件。
</Column>

强化件只能植入于特定槽位。站在强化站上，其界面会列出部件适用的槽位。

***

## <Color id="gold">身体槽</Color>

| 槽位       | 适用的强化件                                                       |
| ---------- | ------------------------------------------------------------------ |
| 头         | 喷口外甲壳、共鸣（共鸣护符）                                       |
| 眼         | 守卫者之眼、深渊之眼                                               |
| 躯干       | 海豚鳍、创造飞行（浮力气罐）、发光皮肤、喷口外甲壳                 |
| 肺         | 溺尸之肺                                                           |
| 心         | 邪能之心、额外红心（辅助心室）                                     |
| 左臂、右臂 | 磁引、末影磁引、水下挖掘速度、弹跳三叉戟、散射三叉戟、投掷随机药水 |
| 左腿、右腿 | 突进、步伐辅助、免疫摔落伤害、行走速度                             |

飞行、海豚鳍、发光皮肤都需要躯干槽位，因此只能三选一。喷口外甲壳可以植入头部槽，让出躯干槽，但也会因此占据共鸣强化件需要的槽位。

共鸣强化件是植入为强化件的[共鸣护符](nautec:deep_engineering/resonance_network.md)，无需占用护符槽即可为你的物品充能。

在两个腿部槽位中植入同种强化件没有增益，建议使用两种不同的强化件。在头部和躯干都植入喷口外甲壳也不会有额外增益。

***

## <Color id="gold">植入</Color>

将部件和爪式机械臂装入已成形[强化站](augmentation_station.md)的扩展单元，向单元下方发射25 AP的光束，再站在中央的方块上，选择槽位再点击“应用”。植入耗时四秒，期间你无法移动。

***

## <Color id="gold">替换和移除</Color>

向已有强化件的槽位植入可替换。之前的强化件会被摧毁而非返还为物品。

若需清空某个槽位，可取走移植站扩展单元中的所有部件，并站到中央的方块上。底部的按钮会列出已植入的强化件。选择一个并点击“移除”。你会和在植入一样被锚定在原地四秒，此时走开会取消移除。移除会将强化件的各部件返还给你，物品的数据和植入前保持一致；共鸣护符能保留其绑定。物品栏已满则掉落在脚下。移除不需要光束或部件。

管理员可以使用`/nautec augments remove <槽位>`（如`nautec:left_arm`）或`/nautec augments clear`，这两个命令会作用于执行命令的玩家。

强化件会在死亡后保留。

***

## <Color id="gold">按键绑定</Color>

大多数强化件不需要外部协助就能运作。下方提及的需要按下按键，各按键均在控制菜单下的海蓝科技分类中：

| 按键（默认） | 按键名称           | 强化件                         |
| ------------ | ------------------ | ------------------------------ |
| B            | 打开强化件界面     | 显示已植入的强化件及其槽位     |
| L（按住）    | 激活守卫者之眼激光 | 守卫者之眼                     |
| 左Alt        | 突进               | 突进（液压腿）                 |
| Y            | 投掷三叉戟         | 弹跳三叉戟（三叉戟投掷臂）     |
| U            | 投掷散射三叉戟     | 散射三叉戟（齐射三叉戟投掷臂） |
| G            | 投掷药水           | 投掷随机药水（注射器机械臂）   |
| 未指定       | 开关磁引强化件     | 开关磁引和末影磁引             |

这些主动强化件都不需要供能或者使用物品。突进和三种投掷臂在使用之后会进入较短的冷却；只要按住按键就能发射守卫者之眼。
