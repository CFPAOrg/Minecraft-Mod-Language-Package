# <Color id="light_purple">潜航</Color>

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="submarine" scale="2"/>
  按键、转向和仪表读数。
</Column>

潜航员可使用常规的移动键驾驶，通过调整视线方向转向，并在其快捷栏原本的位置显示模块栏，还附带储能与外壳完整度的读数仪表。

***

## <Color id="gold">按键</Color>

| 按键（默认）             | 功能                                                 |
| ------------------------ | ---------------------------------------------------- |
| W                        | 前进                                                 |
| S                        | 后退，推力减半                                       |
| 同时按疾跑（Ctrl）和W或S | 推力增加60%                                          |
| 鼠标                     | 转向：潜水器头部会跟随你的视线                       |
| 空格                     | 上升                                                 |
| C                        | 下降                                                 |
| 按住鼠标右键（使用）     | 自由观察：观察四周而不转向，第一人称视角下会淡化船壳 |
| 1至9，或鼠标滚轮         | 选择模块槽                                           |
| 鼠标左击，或F            | 激活所选模块                                         |
| Ctrl + H                 | 移动读数在界面上的位置                               |
| 潜行（Shift）            | 下船                                                 |

C、F、Ctrl + H均在海蓝科技的键位设置中，在控制菜单内分别为“海洋斥候下降”“激活海洋斥候模块”“调整海洋斥候HUD”。三者均可在此重新设置。在潜航时，F键只会激活模块，不会交换副手或开关驭浪推进器的探照灯。

***

## <Color id="gold">转向</Color>

没有单独的转向按键。船壳会跟随你的视线转向，在水下俯仰角双向最多可达75度。松开右键结束自由观察时，你的视角会立即切回船壳前部的方向。

第一人称下，按住自由观察按键会淡化船壳，以便直接观察潜水器下方。可通过客户端配置项`submarineFreeLookHullOpacity`指定不透明度。

船壳只会在有空间的时候转向。向墙壁转向时，船壳会保持原有的朝向而非穿模，因此要先离开狭窄地区才能转向。潜水器的转向碰撞按船壳的真实形状计算。潜水器只会和方块碰撞，撞到鱼和其他生物会推离它们。

在水面时，船壳会保持水平，推进器的力度变为约三分之一，同时也削弱上升和下降能力。在加速前建议潜入水下。

安装有[飞行模块](flight_module.md)时，潜水器能飞出水面：水上水下使用同一套转向和俯仰操作，空格和C能全力上升下降，移动速度变为一半。

推进需要耗能。储能耗空后潜水器会失去动力。

潜航时，第三人称摄像机位于你背后10格处，可以看见整个船体。该距离可配置（`submarineCameraDistance`）。

***

## <Color id="gold">面板读数</Color>

潜航员的屏幕上会出现一个两行的面板，其中PWR代表储能，HULL代表船壳，两者都有百分比读数。其下方会列出控制方式。

* PWR会在降至20%以下时闪烁，储能耗空后显示CHG。
* HULL会在35%以下变红，在15%以下闪烁。

潜航时，该面板会替换原版的载具生命值、快捷栏和经验条。九个模块槽会显示在屏幕最下方快捷栏的位置（参见[模块](submarine_modules.md)）。

在任何情况下按Ctrl + H都可打开调整界面，可在其中将面板拖放到合适的位置，按下Esc或再按Ctrl + H以保存。位置存储于客户端配置。

后座乘客看不到面板，会显示原本的快捷栏。
