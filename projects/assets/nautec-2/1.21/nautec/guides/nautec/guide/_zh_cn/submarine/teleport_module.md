# <Color id="light_purple">传送模块</Color>

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="teleport_module" scale="2"/>
  让潜水器折跃到保存的位置。
</Column>

传送模块可让潜水器携带其乘员折跃到模块中保存的锚点，维度不限。

***

## <Color id="gold">绑定锚点</Color>

手持模块站在水中潜行右击。它会保存你所在的方块、所在的维度和你的朝向，并发出“锚点绑定至”和坐标作为确认。抵达时，潜水器会调整为相应的朝向。再次绑定会替代之前的锚点。

提示文本中会显示锚点及其维度，在潜航员的模块栏中选择模块时，它名字的上方会显示其坐标。各个传送模块可分别存储锚点，也即两个模块可对应两个目的地。所有传送模块共享冷却：折跃后，模块仓中的所有传送模块都将进入30秒冷却。

选取的锚点应在周围有足够空间的开放水域中。潜水器相当庞大，并且折跃需要锚点方块为水，且有空间容纳整个潜水器。

***

## <Color id="gold">折跃</Color>

|              | 默认                        |
| ------------ | --------------------------- |
| 每次折跃能耗 | 200,000                     |
| 折跃所需储量 | 200,000（总容量的五分之一） |
| 蓄能时间     | 2.5秒                       |
| 冷却         | 30秒                        |

潜航员可激活该模块。潜水器前方会打开一道传送门，并将潜水器拉入其中；2.5秒后潜水器就会携带所有乘员出现在锚点处，并向前漂动一小段距离。蓄能时转向功能和其他模块均会锁定。

若模块未设置锚点（“该传送模块未绑定锚点”）、能量库储量少于200,000、锚点不在水体内或对潜水器来说太过狭窄（“锚点被阻挡或不在水中”），即不会进行折跃，也不会消耗储能。蓄能结束时会再次检查锚点。蓄能过程中如有障碍物阻挡了锚点，折跃也会被取消并显示相同的消息，储能会返还至能量库，模块也不会进入冷却，以便直接重新尝试。

折跃是潜水器所能执行耗能最高的操作。在用它回家之前务必充好能。所有数据均可配置。
