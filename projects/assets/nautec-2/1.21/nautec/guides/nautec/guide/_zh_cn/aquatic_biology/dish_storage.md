# <Color id="light_purple">培养皿存放仓</Color>

<Row>
  <ItemImage id="aquarine_dish_storage" scale="2"/>
  <ItemImage id="deep_steel_dish_storage" scale="2"/>
  <ItemImage id="atlantic_gold_dish_storage" scale="2"/>
</Row>

用于存放培养皿的容器。各个培养皿会各自存放在单独的槽位中，能避免弄混品系不同、大小不同、统计数据不同的菌落。

| 方块               | 培养皿数 |
| ------------------ | -------- |
| 海蓝培养皿存放仓   | 48       |
| 深海钢培养皿存放仓 | 96       |
| 海洋金培养皿存放仓 | 192      |

制造各级存放仓时需要用到前一级的存放仓。存放仓只接受培养皿，无论有无菌落。

右击打开。界面中一次显示48个培养皿，可滚动鼠标滚轮或拖动右侧条栏以查看剩下的部分。Shift点击你物品栏中的培养皿会将其放入首个空闲的槽位，不在显示范围内不影响。界面角落的计数器指示了仓中的培养皿数。

漏斗、管道、[海蓝科技分配器](nautec:getting_started/distributor.md)可在任意一面存入和取出培养皿。存放仓旁的比较器可给出填充程度的信号读数。

破坏存放仓会掉落其中所有培养皿。
