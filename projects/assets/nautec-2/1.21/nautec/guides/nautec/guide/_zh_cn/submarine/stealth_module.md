# <Color id="light_purple">隐匿模块</Color>

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="stealth_module" scale="2"/>
  躲过视线两分钟。
</Column>

激活隐匿模块可将潜水器及其乘员在生物眼中隐去两分钟，但会降低速度。

***

## <Color id="gold">使用</Color>

|              | 默认        |
| ------------ | ----------- |
| 每次使用能耗 | 50,000      |
| 持续         | 2分钟       |
| 生效时速度   | 推力降低15% |
| 冷却         | 激活后130秒 |

激活时，32格内本来在攻击船壳或乘员的生物会放弃追击。在接下来的两分钟内，无论生物贴得多近，潜水器及其乘员都无法被它选定为目标。生效时模块所在槽位会显示一个亮色条。

隐匿时，潜水器的推力会降低15%。若想要迅速脱身，可以同时激活[助推模块](booster_module.md)。

隐匿结束后，需要再等待10秒才可再次激活，期间生物可以正常地注意到你。

所有数据均可配置。
