# <Color id="light_purple">助推模块</Color>

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="booster_module" scale="2"/>
  十秒的推力增强。
</Column>

激活助推模块可在接下来的10秒内让推力增加45%。

***

## <Color id="gold">使用</Color>

|              | 默认        |
| ------------ | ----------- |
| 每次激活能耗 | 20,000      |
| 助推         | 推力增加45% |
| 生效         | 10秒        |
| 冷却         | 激活后13秒  |

推进时选择并激活该模块。助推会增加你的推力，能和疾跑键叠加，助推时潜水器尾部还会留下明亮的尾迹。助推结束前，模块所在槽位会出现一个亮色条。

助推效果持续10秒，之后还需再冷却3秒才可再次激活。一次激活消耗20,000点储能，在长途航线中和逃脱追杀时频繁使用也不算开支很大。

配合[隐匿模块](stealth_module.md)使用时，两者的效果相乘，也即最终速度会比正常速度快约23%，而不是变慢。

所有数据均可配置。
