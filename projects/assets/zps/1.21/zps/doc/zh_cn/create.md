# 机械动力兼容

安装有[机械动力](https://modrinth.com/mod/create)时，ZPS会为支持的机械动力方块和机械动力附属方块额外新增执行器。

这些执行器可用于自动化原先需要玩家调整的机械动力指标，如转速、模式、范围、堆叠数量等。

可在脚本终端中用Tab自动补全来查看目标方块可以使用哪些`set_*`命令。目标方块不同，加载的机械动力附属不同，命令列表的内容也不同。

---

## 常用命令

| 执行器                                  | 参数     | 描述                                   |
| --------------------------------------- | -------- | -------------------------------------- |
| `set_filter`                            | `<item>` | 在支持的机械动力方块上设置物品过滤器。 |
| `set_产生的rpm转速`/`set_目标的rpm转速` | `<int>`  | 设置方块的转速，以RPM计。              |
| `set_运动模式`                          | `<模式>` | 改变动力轴承的模式。                   |
| `set_沿时钟指针排列`                    | `<模式>` | 改变时钟轴承的指针排列。               |
| `set_粘附距离`/`set_粘附半径`           | `<int>`  | 改变底盘的粘附距离/半径。              |
| `set_弹射物品堆数量`                    | `<int>`  | 设置弹射置物台的弹射堆叠数量。         |

例如：

```
set_filter minecraft:iron_ingot
set_目标的rpm转速 64
set_运动模式 ROTATE
set_粘附距离 4
set_弹射物品堆数量 16
```

---

## 适用范围

部分常见的受支持方块有：

- `set_filter`：动力锯、机械手、列车侦测器、存量转信器、物品舱口、黄铜漏斗、智能流体管道、智能侦测器、智能溜槽、动力压路机、工作盆
- `set_产生的rpm转速`/`set_目标的rpm转速`：创造马达、转速控制器
- `set_运动模式`：动力轴承
- `set_沿时钟指针排列`：时钟轴承
- `set_粘附距离`/`set_粘附半径`：轴向底盘、轴向底盘二号、径向底盘
- `set_弹射物品堆数量`：弹射置物台

若某条命令未在目标方块的Tab自动补全中出现，就意味着该方块不支持该命令。

---

## 在脚本中使用机械动力命令

机械动力执行器的使用方法和其他执行器的一致，也即可以使用字面量、`value_of(...)`、条件判断：

```
set_rpm value_of(redstone * 8)
```

```
if redstone > 7 set_运动模式 ROTATE_PLACE
```

```
if block == create:weighted_ejector set_弹射物品堆数量 16
```
