# Sable兼容

这些值只在安装有[Sable](https://github.com/ryanhcode/sable)时有意义。

---

## 获取器

| 获取器     | 输出     | 描述                                                                 |
| ---------- | -------- | -------------------------------------------------------------------- |
| `sublevel` | SubLevel | 返回包含目标方块位置的子维度。若目标不在子维度内，会返回一个哨兵值。 |

---

## 子维度映射器

获取自：`sublevel`

| 映射器         | 输出    | 描述                                                                                                                 |
| -------------- | ------- | -------------------------------------------------------------------------------------------------------------------- |
| `name`         | String  | 子维度的显示名称。未命名或不在子维度内返回`""`。                                                                     |
| `id`           | String  | 子维度的UUID字符串。不在子维度内返回`""`。                                                                           |
| `pos`          | Vec Pos | 全局空间中的子维度姿态位置。不在子维度内返回目标方块自身的中心位置。                                                 |
| `world_vel`    | Vec Dir | 目标位置的全局速度，考虑子维度中的运动。不在子维度内返回零。                                                         |
| `local_vel`    | Vec Dir | 旋转至子维度局部框架的目标方块速度。不在子维度内返回零。                                                             |
| `bounding_box` | Vec Box | 局部空间中的子维度边界框，单位为格。不会因子维度旋转而变。不在子维度内返回零。                                       |
| `dir <方向>`   | Vec Dir | 旋转至符合子维度当前朝向的正方向（`north`、`south`、`east`、`west`、`up`、`down`）。不在子维度内返回未经旋转的方向。 |

---

## 示例

检验方块是否在子维度内：

```
if sublevel id == "" set_redstone 0 else set_redstone 15
```

根据子维度向上运动与否设置红石信号：

```
if sublevel world_vel y > 0 set_redstone 15
```

检验子维度中北方的指向：

```
if sublevel dir north y < 0 set_redstone 15
```

子维度足够大时激活：

```
if sublevel bounding_box volume > 1000 set_redstone 15
```
