# 执行器

执行器（executor）会对目标方块执行动作。所有执行器都需接受一个参数，可以是字面量，也可以是`value_of()`表达式。

部分执行器只有特定类型的方块可用。若目标方块与执行器不兼容，则只会跳过该执行器。

---

## 所有方块

可用于：任意目标方块

| 执行器          | 参数     | 描述                                                                        |
| --------------- | -------- | --------------------------------------------------------------------------- |
| `set_redstone`  | `<0-15>` | 串行总线会向目标方块通入红石信号，如同有中继器。                            |
| `request_value` | `<值>`   | 串行总线会向脚本终端的`receive_value`回应所给值。见[变量](syntax.md#变量)。 |

例如：

```
set_redstone 15
set_redstone value_of(page_number - 1)
if pos == @lectern request_value value_of(page_number)
```

---

## 数据讲台 / 讲台

下方命令需要目标方块为放有书的`数据讲台`或普通`讲台`。

| 执行器       | 参数       | 描述                                  |
| ------------ | ---------- | ------------------------------------- |
| `set_page`   | `<1-100>`  | 设置书当前翻开至哪一页。页码从1起始。 |
| `write_page` | `<string>` | 向当前页写入文本，替换已有内容。      |

例如：

```
set_page 1
set_page value_of(redstone + 1)
```

```
write_page "Hello, world!"
write_page value_of(dimension as_string)
```

---

## 脚本终端

下方命令需要目标方块为`脚本终端`。

| 执行器        | 参数       | 描述                                                |
| ------------- | ---------- | --------------------------------------------------- |
| `load_script` | `<string>` | 替换终端的脚本，和玩家从`.mungus`中加载的效果一样。 |

所给字符串的各行变为脚本的各行；在引号字符串中，换行可写为`\n`。若第一行为形如`# 4t REPEAT`或`# 8t IMPULSE`的头部，则它会设置终端的延迟和模式，且该行不置入脚本。没有头部时，终端会保留当前的延迟和模式。头部的延迟若不为2、4、8或16，则会保留原有的延迟。

在引号字符串内部，需将`"`写为`\"`，将`\`写为`\\`，也即所加载脚本中的换行应转义写为`\\n`。来自`value_of()`的值则无需转义：其中的换行和反斜杠会原样传入。加载终端中已有的脚本，同时延迟和模式也相同，便不会改变任何设置。超过32500个字符的脚本会被跳过，线缆中一行最多可有3600个字符。

例如：

```
load_script "# 4t REPEAT\nif redstone > 0 set_redstone 15"
load_script "write_page \"你好啊\""
load_script value_of(code)
```

从一个终端复制到另一个终端，两者均贴有串行总线：

```
#var code = none
if pos == @source request_value value_of(script_contents)
receive_value code
if pos == @copy load_script value_of(code)
```

## 无线电发送器 / 无线电接收器

下方命令需要目标方块为`无线电发送器`或`无线电接收器`。

| 执行器          | 参数     | 描述                                        |
| --------------- | -------- | ------------------------------------------- |
| `set_frequency` | `<频道>` | 设置该方块所在的无线电频道（1到64的整数）。 |

例如：

```
set_frequency 10
```

## 机械臂

下方命令需要目标方块为`机械臂`。

和其他执行器不同，这些执行器需要**方块位置**（`x y z`）参数作为机械臂的目标位置，而不接受作用于机械臂本身的值。机械臂会先将手移至该位置，再执行动作。目标须在机械臂4格范围内，超出范围的位置会被跳过。机械臂`每16刻只接受一次`让其移动的机械臂。

| 执行器               | 参数      | 描述                                                                          |
| -------------------- | --------- | ----------------------------------------------------------------------------- |
| `take_items`         | `<x y z>` | 从目标位置的容器中取出物品至机械手。                                          |
| `put_items`          | `<x y z>` | 将机械手中的物品存入目标位置的容器。                                          |
| `use`                | `<x y z>` | 用手持物品右击目标（放置方块、倒空/装填铁桶、使用物品等）。                   |
| `shift_use`          | `<x y z>` | 用手持物品潜行右击目标。                                                      |
| `drop_items`         | `<x y z>` | 在目标位置将手持物品丢出为物品实体。                                          |
| `break`              | `<x y z>` | 立即如同使用铁镐一样破坏目标方块。掉落物进入机械手。                          |
| `silk_break`         | `<x y z>` | 和`break`类似，但会使用精准采集铁镐，因此方块会掉落自身（玻璃、石头、矿石）。 |
| `set_transfer_count` | `<int>`   | 设置`take_items`、`put_items`、`drop_items`移动的物品量（1-64）。             |

每一条`take_items`、`put_items`、`drop_items`指令最多只能移动机械臂GUI中指定的**运输量**（1–64），剩余的部分留在机械手中。`use`和`shift_use`会用手持物品交互，不会运输物品。

`break`和`silk_break`只会破坏铁镐能破坏的方块；机械臂仍然会移动到无法被它破坏的方块处，只是不会破坏而已。机械手中无法容纳的掉落物会掉落在世界中。

例如：

```
take_items 1 3 5
put_items 0 1 2
set_transfer_count 16
drop_items 0 2 2
break 1 1 3
silk_break 1 2 3
```

```
use 0 1 2
use value_of(pos offset_y 1)
```
