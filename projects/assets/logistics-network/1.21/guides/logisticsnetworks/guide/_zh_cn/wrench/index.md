# 扳手

扳手是用于与节点的一切信息交互的工具：打开节点配置、移除节点、在节点间复制设置，以及一次性批量放置多个节点。

扳手有三个模式。手持扳手时按住**R**可打开模式轮盘菜单，指向某模式后松开键位即可切换至该模式。鼠标留在中间时松开，或按下Esc，均可取消。可在Minecraft的控制菜单中重新绑定轮盘菜单键位。

也可通过**修饰键1（默认：Shift）+滚轮**循环切换模式。当前模式会在快捷栏旁以HUD叠加层显示：扳手模式为蓝色，复制/粘贴模式为绿色、批量放置模式为金色。

## 模式概览

- [扳手](wrench-mode.md)：默认模式。打开节点配置，移除节点，以及链接至AE2或精致存储网络。
- [复制/粘贴](copy-paste.md)：复制节点的整套配置——频道、过滤器、升级、标签——再粘贴到其他节点中去。支持对依附于同种方块的相连节点进行批量粘贴。
- [批量放置](mass-placement.md)：选择两个角点，再选择目标方块类型，最后可通过**主要交互键（默认：左键）**一次性在所有匹配的方块上放置经过配置的节点。

## 扳手设置

持有扳手时按下**G**可打开其设置。各扳手会独立保存设置，因此可以安排一个扳手显示整个基地，再安排另一个扳手专门显示某个网络。

**Colors**（**颜色**）会为扳手的外壳和屏幕重新上色。

**Flow Lines**（**流向线**）对应手持扳手时在输出端和输入端之间绘制的线。

- *Simple*（*常规*）：
  - 开关流向线的显示
  - 仅为部分资源显示（物品、流体、能量、化学品、魔源）
  - 仅为部分频道显示（1–9）
  - 仅显示附近单个网络的流向线
  - 在游戏窗口外或超出渲染距离的节点是否仍显示流向线。会搜索游戏追踪的所有节点，大约64格。
- *Advanced*（*高级*）：
  - 选择流向线样式：**Routed**（**路由**，经过汇总的直角路线）或**Direct**（**直连**，从各输出端连向各输入端的直线）
  - 设置粗细、速度、不透明度、脉冲
  - 流向线是否能透过方块看见
  - 为不同资源类型设置颜色

按下**应用**以保存。**Reset**（**重置**）会将你所用扳手的各设置恢复默认。

## 速查表

| 模式      | 次要交互键（默认：右键）                      | 修饰键1+次要交互键                   | 修饰键2（默认：Ctrl）+次要交互键 |
| --------- | --------------------------------------------- | ------------------------------------ | -------------------------------- |
| 扳手      | 打开节点配置                                  | 移除节点、放置节点、开关存储网络链接 | —                                |
| 复制/粘贴 | 复制，节点 → 剪贴板（对空气交互时打开剪贴板） | 粘贴，剪贴板 → 节点                  | 粘贴至相连所有同类方块上的节点   |
| 批量放置  | 选择角点（对空气交互时打开放置菜单）          | 打开放置菜单                         | —                                |

## 使用扳手操作标签

标签和扳手之间配合良好。向节点粘贴设置时，来源的标签也会被粘贴——粘贴后的节点会加入标签组，并和其他使用同一标签的节点保持同步。

惯用工作流：

1. 按需配置一个节点。
2. 为其设置标签（参见[标题 → 设置标签](../nodes/header.md)）。
3. 将其配置复制到扳手剪贴板。
4. 粘贴（或批量放置）至其他应使用相同设置的节点。

这之后，所有节点就将使用同一个标签。后续对其中一个的编辑操作会自动同步至整个标签组。微调时无需重新复制粘贴。
